# PRD - pre-talk（想清楚）

## 问题

重要沟通前的准备是散的：打腹稿等于只有情绪和意图总量；写提纲等于列了很多条但没有排序。临场按想到的顺序说，被对方一带就走，事后才想起最想说的那句没说。市面上的「沟通话术」内容教的是句式（练嘴），而表达问题的根源在开口前的构思（练脑），背话术临场想不起来，因为没有改变思考方式。

## 用户与场景

需要面对重要对话的人：向上汇报、谈薪、合作谈判、1on1、提需求、面试。用户已有自己的 AI agent（Claude Code / OpenCode / Cursor 等），缺的是一个固定的准备工序。

## What

一个 Agent Skill（本仓 `skill/`）：对话式四步（登记 → 核心句工作坊 → 排序卡 → 对方预设三问），10 分钟产出一张备谈卡。卡是 Markdown，人机共读，可留档。

## 非目标

- 不做沟通中的实时辅助：该层由「听懂对方」（Rokid AI Glasses 智能体）承担，本仓只通过 60 字眼镜开场白做方向锚，不做设备功能。
- 不做事后复盘工具：复盘归用户自己的记录与定期回顾。
- 不生成让人背的话术模板：只给构思程序，不给嘴巴句式。
- v1 不做云同步、多端、账号体系。

## 成功标准

1. 一次备谈 10 分钟内产出通过 `scripts/check_card.py` 的卡。
2. 开场第一句在真实对话中被用户实际使用（自报即可）。
3. 用户自评：临场被拉扯时能照排序取舍，没有再卡在「排序没想过」上。
4. 开源信号：GitHub star / fork / agent 社区转载（配合 Rokid 比赛曝光）。
