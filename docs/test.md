# Test - 分层验证

## L0 结构校验（无 LLM，确定性）

```bash
./scripts/check_card.sh
```

覆盖：示例卡全字段（核心句非空且 ≤60 字、排序含 1./2.、三问表数据行、开场第一句、眼镜开场白 ≤60 字）+ 模板 headers-only 模式。

## L1 工作流冒烟（人工，改 SKILL.md 后必做）

在一个干净会话里对 agent 说「我明天要跟老板谈 X，帮我备谈」，核对四点：

1. 四步顺序未被跳步或重排；
2. 核心句经过筛除三标准，而非直接让用户「挑最重要的」；
3. 排序区出现「第二重要」，且引导语带试金石；
4. 产出卡通过 `python3 scripts/check_card.py <卡路径>`。

## L2 真机配合（可选）

戴「听懂对方」智能体，开场白口播后进入对话，确认设备教练的方向提示与卡内排序一致。仅在与设备端联调变更时执行。
