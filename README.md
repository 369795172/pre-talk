# pre-talk · 想清楚

重要沟通前的 10 分钟，和你的 AI 一起想清楚三件事：**核心句、优先级、对方会问什么**。产出一张备谈卡。

> 先想清楚，再听懂对方。

## 为什么

重要沟通前的准备通常是散的：打腹稿，脑子里只有情绪和意图总量；写提纲，列了很多条但没有排序。结果临场按想到的顺序说，被对方一带就走，回来才想起「我最想说的那句没说」。

本 skill 把准备变成一个固定工序：不是背话术，是开口前把脑子里的东西排好序。方法论源自黄执中《表达学院》系列公开课（见文末致谢），核心就三条：

1. **核心句靠筛除，不靠挑选**：把想说的全列出来，按「可剔除 / 可合并 / 排序低」三个标准删，删到剩那句删不掉的。如果对方离场只带走一句话，是哪句？
2. **排序即指挥官命令**：说得出「第二重要」的排序才算排序，否则是口号。有了排序，现场遇到拉扯和时间不够，照序让步，不用临场纠结。
3. **最重要的话放第一句**：诉求在前，机制后补。对方扫一眼第一句就知道你要什么。

## 三分钟上手

把 `skill/` 目录装进你的 agent（支持 Agent Skills 格式的均可）：

```bash
# Claude Code
cp -r skill/ ~/.claude/skills/pre-talk/

# OpenCode（项目级）
mkdir -p .opencode/skills && cp -r skill/ .opencode/skills/pre-talk/

# Cursor
mkdir -p .cursor/skills && cp -r skill/ .cursor/skills/pre-talk/
```

然后对你的 agent 说：

```
我明天下午要跟老板谈加薪，帮我备谈
```

agent 会带你走四步：登记场景 → 核心句工作坊（筛除法）→ 排序卡 → 对方预设三问，最后产出备谈卡：

```
# 备谈卡：跟老板谈调薪
- 对象：直属上级，关心预算与团队稳定性
## 核心句
这次调薪谈的是我下半年的职责范围变化，不是生活成本。
## 重要性排序
1. 职责扩大被正式承认（=核心句诉求）
2. 调薪生效时间
- 可让步：具体数字本月内二轮沟通
...（完整模板见 skill/talk-card.template.md）
```

## 与助谈设备配合（如实说明）

备谈卡末尾的「眼镜开场白」（60 字以内）首先是给自己用的：开口前把核心句念出声，第一句话先进你自己的脑子。它同时是一段现成的导出物——任何支持「会前简报 / 会话预载」的助谈工具都可以直接消费这段话。

如实说明：Rokid AI Glasses 上的「听懂对方」智能体（Agent Store 可订阅）目前是单轮会话制，每次结算后上下文即销毁，暂不支持把开场白作为跨轮上下文注入。设备端未来支持会前定锚时，本节会更新为具体操作步骤。

三层闭环：

| 层 | 时机 | 工具 |
|---|---|---|
| 想清楚 | 沟通前 | 本 skill（开源，装进你自己的 agent） |
| 听懂对方 | 沟通中 | 助谈设备，或你训练出来的专注力 |
| 复盘提高 | 沟通后 | 你自己的笔记与定期回顾 |
